# Example Skill

This is an example skill demonstrating the Claude Code marketplace plugin structure.

## Usage

Invoke this skill by typing:

```
/example-skill
```

## Structure

This plugin follows the standard Claude Code plugin structure:

- `.claude-plugin/plugin.json` - Plugin metadata
- `skills/` - Skill definitions
- `README.md` - This documentation

## Customization

Modify the `SKILL.md` file to customize this skill's behavior.
